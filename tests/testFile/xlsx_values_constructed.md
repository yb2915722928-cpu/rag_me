## 预设缓存的事实边界

构造器先用 openpyxl 写工作簿，再只修改 worksheet OOXML 的单元格类型和 v 元素，公式 f 元素保持不变。这些缓存是人为预设值，**不是 Excel、LibreOffice 或其他办公软件重算的结果**。构造器和测试均不导入生产值适配代码，不借助公式执行生成期望。

| 坐标 | 输入／缓存及格式 | 独立固定期望 |
| --- | --- | --- |
| B2 | =1-1，缓存 0 | cached，文件缓存：0，非实时 |
| B3 | =1+1，无缓存 | unknown，结果未知，独立 formula 警告 |
| B4 | =40+2，缓存 42 | cached，文件缓存：42 |
| B5 | =1/0，错误缓存 #DIV/0!，0.00 | 错误：#DIV/0!，不显示普通数值 |
| B6–B8 | 普通空白、零、错误 #VALUE! | None／空文本、0、错误：#VALUE! |
| B9–B11 | 1234／#,##0；-1234.5／#,##0.00；12.5／0.00 | 1,234；-1,234.50；12.50 |
| B12–B13 | 0.2／0%；0.125／0.00% | 20%；12.50% |
| B14–B15 | 1234.5／"¥"#,##0.00；-12.5／$0.00 | ¥1,234.50；-$12.50 |
| B16–B18 | 2026-10-27；同日 13:04:05；时间 13:04:05 | 2026-10-27；2026-10-27T13:04:05；13:04:05 |
| B19 | =1/5，缓存 0.2，0% | 文件缓存：20% |
| B20 | =DATE(2026,10,27)，缓存 46322，yyyy-mm-dd | openpyxl 读取为 datetime，文件缓存：2026-10-27 |
| B21 | 12.5，0.0" widgets" | 原值文本 12.5，独立格式警告，不猜 widgets |
| B22–B23 | False、文本 00123，均设置 0.00 | False、00123；保持原类型 |
| B24 | =25/2，缓存 12.5，0.0" widgets" | 保留表达式和缓存，独立格式警告 |
| B25 | =2500/2，缓存 1250，"¥"#,##0.00 | 文件缓存：¥1,250.00 |
| B26–B27 | IF 文本缓存 00123、比较公式布尔缓存 False，0.00 | 文件缓存：00123／False，不转数字 |
| B28 | 日期，自定义 yyyy"年"m"月"d"日" | 原日期对象，原值文本，独立格式警告 |
| B29 | 12000，#,##0, | 12000，独立格式警告，不猜倍率 |
| B30–B32 | 2.675／0.00；2.5／0；-2.5／0 | 2.68；3；-3 |

完整上下文下应有五条独立警告：B3 缺缓存，以及 B21、B24、B28、B29 的不支持格式；它们均不混入正文或独立行文本。所有期望来自上述固定输入和人工明确的显示语义。
