# Markdown 构造样本

这些样本为 Issue #3 在本地手工构造，输入统一保存在本目录；测试不联网。
公开下载的 Markdown 和其他格式样本未修改。

- `md_structure.md`：UTF-8 无 BOM；以 CRLF 为主，最后一个段落分隔使用单独 CR。
  包含中文、三级标题、嵌套列表、普通表格、行内与引用链接、段落间连续空行、
  行内双空格及行末两个空格硬换行。仅统一换行和压缩冗余空行，内容结构不变。
- `md_fenced_code.md`：UTF-8、CRLF；四个反引号与波浪线围栏中的连续空行、
  制表符、行末空格、短围栏、不同类型围栏及带正文的伪结束行必须保留。
  仅在匹配类型且长度足够、行尾没有正文的结束围栏后恢复空行整理。
- `md_indented_code.md`：UTF-8、LF，无文件末尾换行；四空格与制表符缩进代码，
  含多行字符串、内部连续空行、只有四空格的空白行和代码中的反引号。
  代码空白及结尾保持，后续普通段落间的冗余空行整理。
- `md_list_fence.md`：UTF-8、LF；围栏直接出现在列表项目标记后，代码行缩进两空格，
  内部连续空行不得压缩，结束围栏后的列表及子列表关系不变。
- `md_gb18030.markdown`：GB18030 无 BOM、CRLF；中文标题及北京、武汉、兰州事实，
  两段间额外空行。用于 `.markdown` 后缀、显式编码、严格解码失败及编码探测验证。
- `md_truncated_utf16.md`：原始字节 `ff fe 23 00 20 00 78`，UTF-16 LE BOM 后
  最后一个码元被截断；严格解码必须失败，不回退到猜测编码。
- `md_utf8_bom.md`：UTF-8 BOM、CRLF；中文标题和正文，标题后含两行空行。
  BOM 在规范化前移除，导出不含 BOM。
- `md_bom_only.md`：仅含 UTF-8 BOM（`ef bb bf`）；`md_whitespace.md`：UTF-8，
  字节为 `20 0d 0a 09 0d 0a`（空格、CRLF、制表符、CRLF）。两者均无可用正文。

本目录的 `.gitattributes` 使用 `-text`，构造样本同样按原始字节提交。
